Category picker in the web register panel, same as the phone: most-used shortcuts plus «Más», and a sheet with rubro pills, categories that expand into subcategorías, and search.
Branch: feat/selector-de-categoria. Runner: `npx vitest run <files>`.

## Specs

- S1 User: "para registrar gastos quiero que sea igual que la app, seleccionar el rubro subcategoras etc".
- S2 Behavior copied from the phone (lib/features/registro/presentation/widgets/atajos_de_categoria.dart, selector_categoria.dart): heading «¿En qué fue?» (expense) / «¿De dónde viene?» (income); grid of up to 7 most-used leaves (count of the household's last 1000 movements per category_id, current kind, live leaves; with no history the first leaf of each rubro; the chosen one first) plus «Más»; under it the short path («Rubro › Categoría» when the leaf is «General», else «Categoría › Subcategoría») or «Toca una, o «Más» para ver todas». «Más» opens a picker: search «Buscar categoría» (case/accent-insensitive on rubro, categoría, subcategoría; flat results with subtitle; empty → «No hay categorías que coincidan. Puedes crearla en Secciones › Categorías.»), horizontal rubro pills (photo or color, selected with a green ring), header «{Rubro} · N opciones», category rows with «N subcategorías» and a chevron, one expanded at a time, indented subcategorías, check on the current one; a category whose only leaf is «General» is chosen in one tap (its General id); otherwise «General» is never offered; opens on the current selection. Hidden: archived/deleted at any level, the other kind, the balance-adjustment rubro (idDelRubroDeAjuste). Order: rubro, categoría, subcategoría sort_order.
- S3 Out of scope: inline category creation (no server function), icons glyph map (photo or color dot instead).
